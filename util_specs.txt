1. TỔNG QUAN VAI TRÒ (OVERVIEW)
--------------------------------------------------------------------------------
- Tệp `util.py` đóng vai trò là Model Registry (Sổ đăng ký mô hình) và Checkpoint Loader.
- Nhiệm vụ:
  + Lưu trữ toàn bộ bảng ánh xạ cấu hình cho 6 biến thể mô hình FLUX.2 (`FLUX2_MODEL_INFO`).
  + Tự động tải hoặc nạp từ file local cho Trọng số DiT (`load_flow_model`),
    Text Encoder (`load_text_encoder`) và VAE AutoEncoder (`load_ae`).
  + Tối ưu hóa bộ nhớ khi nạp mô hình lớn thông qua `torch.device("meta")` và `safetensors`.

3. KỸ THUẬT NẠP TRỌNG SỐ TỐI ƯU (ZERO-MEMORY INITIALIZATION)
--------------------------------------------------------------------------------
- Vấn đề: Nếu khởi tạo mô hình 32B (FLUX.2-dev) theo cách thông thường `model = Flux2()`,
  PyTorch sẽ cấp phát ngẫu nhiên ~64GB RAM, sau đó nạp file safetensors lại tốn thêm 64GB
  -> Gây tràn RAM hệ thống (Out of Memory).

- Giải pháp trong FLUX.2:
  1. Sử dụng `with torch.device("meta"): model = Flux2(...)`
     -> Tạo cấu trúc mô hình ảo trên thiết bị `meta`, tiêu tốn 0 byte RAM.
  2. Nạp trực tiếp ma trận trọng số từ ổ đĩa bằng `safetensors.torch.load_file(weight_path)`.
  3. Gán con trỏ tensor vào mô hình bằng `model.load_state_dict(sd, strict=True, assign=True)`
     -> Loại bỏ hoàn toàn bước nhân đôi RAM.


4. CÁC HÀM TIỆN ÍCH CHÍNH
--------------------------------------------------------------------------------
- load_flow_model(model_name, debug_mode=False, device="cuda"):
  + Nạp mô hình DiT tương ứng.
  + Hỗ trợ `debug_mode=True` (chỉ khởi tạo 1 DoubleBlock và 1 SingleBlock để test nhanh).

- load_text_encoder(model_name, device="cuda"):
  + Tự động gọi hàm nạp Qwen3 hoặc Mistral-Small phù hợp với mô hình được chọn.

- load_ae(model_name, device="cuda"):
  + Nạp AutoEncoder (VAE) từ `ae.safetensors`.

- image_to_base64(image):
  + Chuyển đổi ảnh PIL sang chuỗi Base64 (PNG) để phục vụ gửi ảnh tham chiếu qua OpenRouter API.
