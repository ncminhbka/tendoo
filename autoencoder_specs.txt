THÔNG SỐ KỸ THUẬT VÀ KIẾN TRÚC - FLUX.2 AUTOENCODER (VAE)
Tệp tham chiếu: src/flux2/autoencoder.py
================================================================================

1. THÔNG TIN CHUNG VÀ TRỌNG SỐ (GENERAL INFO)
--------------------------------------------------------------------------------
- Tên model           : FLUX.2 AutoEncoder (VAE)
- Kiến trúc           : Convolutional Variational AutoEncoder kết hợp Spatial
                        Self-Attention, 2x2 Patchification và BatchNorm Normalization.
- Tệp trọng số        : ae.safetensors (~335MB)
- Repo nguồn          : black-forest-labs/FLUX.2-dev (dùng chung cho cả bản Klein và Dev)
- Giấy phép (License) : Apache 2.0 (Mở hoàn toàn cho thương mại và tùy biến)


2. SIÊU THAM SỐ CẤU HÌNH (AutoEncoderParams)
--------------------------------------------------------------------------------
- in_channels         : 3 (Ảnh đầu vào RGB)
- out_ch              : 3 (Ảnh đầu ra RGB tái tạo)
- ch (Base channels)  : 128 (Số kênh tích chập cơ sở ở tầng đầu)
- ch_mult             : [1, 2, 4, 4] (Hệ số nhân kênh qua 4 cấp độ phân giải)
                        -> Level 0: 128 channels
                        -> Level 1: 256 channels
                        -> Level 2: 512 channels
                        -> Level 3: 512 channels
- num_res_blocks      : 2 (Số lượng khối ResnetBlock trên mỗi cấp độ phân giải)
- z_channels          : 32 (Số kênh latent thô xuất ra từ Encoder)
- resolution          : 256 (Kích thước phân giải chuẩn cơ sở)


3. HỆ SỐ NÉN KHÔNG GIAN VÀ BIẾN ĐỔI TENSOR (TENSOR SHAPE TRANSFORMATIONS)
--------------------------------------------------------------------------------
a) Giai đoạn Encode Input:
   - Input Image (RGB)        : Shape = (B, 3, H, W) trong khoảng [-1, 1]
   - Encoder Output (mean)    : Shape = (B, 32, H/8, W/8)
     (Qua 3 tầng Downsample, hệ số nén VAE cơ sở: 2^(4-1) = 8x)

b) Giai đoạn Patchification (ps = [2, 2]):
   - Gom các ô 2x2 pixel liền kề vào chiều kênh (channel dimension)
   - Công thức chuyển đổi:
     "... c (i pi) (j pj) -> ... (c pi pj) i j" với pi=2, pj=2
   - Số kênh mới = 32 * (2 * 2) = 128 channels
   - Kích thước không gian = (H/8)/2 = H/16, (W/8)/2 = W/16
   - Shape sau Patchify       : (B, 128, H/16, W/16)

c) Giai đoạn Latent Normalization:
   - Áp dụng BatchNorm2d với running_mean và running_var có sẵn trong trọng số.
   - Latent hoàn chỉnh cho DiT : Shape = (B, 128, H/16, W/16)
   - Độ dài chuỗi (Tokens vào DiT): L = (H/16) * (W/16)

d) Giai đoạn Decode (Tái tạo ảnh):
   - Input Latent từ DiT      : (B, 128, H/16, W/16)
   - Inverse BatchNorm        : z_denorm = z * sqrt(running_var + eps) + running_mean
   - Unpatchify (2x2)         : (B, 128, H/16, W/16) -> (B, 32, H/8, W/8)
   - Decoder Output           : (B, 3, H, W) trong khoảng [-1, 1]

* TỔNG KẾT NÉN KHÔNG GIAN:
  Tổng hệ số nén không gian thực tế = 8 * 2 = 16x.
  Ví dụ: Ảnh 1024x1024x3  -->  Latent 64x64x128 (4096 tokens, 128 channels).


4. CHI TIẾT CÁC KHỐI KIẾN TRÚC CON (BUILDING BLOCKS)
--------------------------------------------------------------------------------
a) AttnBlock (Spatial Self-Attention):
   - Vị trí: Middle block (tầng sâu nhất của Encoder và Decoder, 512 channels).
   - Kiểu Attention: 2D Spatial Self-Attention (dùng F.scaled_dot_product_attention).
   - Chiếu Feature: Q, K, V và Proj Out đều dùng Conv2d(kernel=1x1).
   - Chuẩn hóa trước: GroupNorm(num_groups=32, num_channels=in_channels, eps=1e-6).

b) ResnetBlock (Tích chập dư):
   - Cấu trúc: GroupNorm(32) -> Swish -> Conv2d(3x3) -> GroupNorm(32) -> Swish -> Conv2d(3x3)
   - Residual Shortcut: Conv2d(1x1) khi in_channels != out_channels, ngược lại là Identity.

c) Downsample:
   - Padding bất đối xứng: nn.functional.pad(x, (0, 1, 0, 1), mode="constant", value=0)
   - Conv2d(kernel=3, stride=2, padding=0) -> Giảm kích thước 2x.

d) Upsample:
   - nn.functional.interpolate(scale_factor=2.0, mode="nearest")
   - Conv2d(kernel=3, stride=1, padding=1) -> Tăng kích thước 2x.

e) Hàm kích hoạt (Activation):
   - Swish / SiLU: f(x) = x * sigmoid(x)

f) Chuẩn hóa Latent (BatchNorm2d):
   - Số kênh: 128 (32 * 2 * 2)
   - eps = 1e-4, momentum = 0.1, affine = False, track_running_stats = True.


5. SO SÁNH VỚI CÁC THẾ HỆ VAE TRƯỚC
--------------------------------------------------------------------------------
- Stable Diffusion 1.5 / SDXL:
  + Số kênh Latent: 4 channels
  + Hệ số nén: 8x
  + Nhược điểm: Mất nhiều chi tiết vi mô, render chữ dễ bị méo.

- FLUX.1:
  + Số kênh Latent: 16 channels thô (patchify 2x2 -> 64 channels cho DiT)
  + Hệ số nén: 8x (patchify -> 16x tổng hợp)

- FLUX.2:
  + Số kênh Latent: 32 channels thô (patchify 2x2 -> 128 channels cho DiT)
  + Hệ số nén: 8x (patchify -> 16x tổng hợp)
  + Ưu điểm vượt trội: Giữ nguyên chi tiết chữ, mắt, vân tay, kết cấu bề mặt cực kỳ sắc nét.
